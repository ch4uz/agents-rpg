# Agents TTRPG

The idea is to create an experiment where 2 ReACT agents and a Human are playing a Tabletop Rpg: HeroKids.
The Dungeon Master will also be an agent.
The Journey is already created.

# ReACT Agents

Agents should use the ReACT framework, enabling them to solve complex tasks by interleaving step-by-step reasoning ("thoughts") with external tool usage ("actions") and environmental feedback ("observations").

# Interface

Render the TTRPG on a 2D environment inside the browser.
